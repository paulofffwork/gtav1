Hosting "GTA Craft" on GitHub Pages:

  1. Create a new public repository on GitHub (e.g., gtacraft).
  2. Create a file named index.html in the repository root.
  3. Paste this entire single file into index.html and commit.
  4. Navigate to Settings → Pages.
  5. Set Source to Deploy from a branch, select branch main, and Save.
  6. Your game will be live online instantly!
